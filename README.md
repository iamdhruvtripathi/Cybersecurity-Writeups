Hacker Holidays is a free, beginner-friendly event hosted by TryHackMe, with a new challenge room released daily starting July 27, 2026. Challenges cover OSINT, web exploitation, cloud security, forensics and AI prompt attacks

The story is set at The Byte Lotus 🪷, a fictional five-star resort with a *"zero-star security posture."* Participants uncover hidden secrets, investigate suspicious activity and solve practical security challenges through a story-driven experience
